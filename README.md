### 覆盖领域

组织行为学（OB）与人力资源管理（HRM）的核心研究变量，包括但不限于：

- 工作态度（工作满意度、组织承诺、离职意向）
- 领导力（变革型领导、服务型领导、授权型领导）
- 工作特征（工作自主性、工作复杂性、角色压力）
- 组织公正（分配公正、程序公正、互动公正）
- 心理资本（自我效能、韧性、希望、乐观）
- 知识管理、创新行为、团队效能……

## Usage

### 搜索量表

在左侧搜索框输入关键词（量表名、变量名、作者名、题项内容），结果实时过滤。

### 浏览目录

左侧目录树按研究主题分类组织，点击即可展开查看该类别下的所有量表。

### 查看详情

点击任意量表条目，右侧显示完整信息：

- 量表名称与来源文献
- 题项内容与计分方式
- 信效度信息
- 适用场景说明

### 复制引用

点击详情页的「复制引用」按钮，即可获得标准化的文献引用格式，直接粘贴到论文中。

### 提交新量表

发现库中缺少某个量表？点击「提交新量表」，填写信息后即可提交，审核通过后会加入下一次更新。

本量表库的数据来自多个渠道：

- **[OBHRM百科](https://www.obhrm.net/)**：部分量表信息来源于 OBHRM百科——华人 OBHRM 学者共建共享的公益性知识库。该网站采用 [CC BY-NC-SA 3.0](https://creativecommons.org/licenses/by-nc-sa/3.0/) 协议，本项目遵循相同协议。
- **学术文献**：部分量表信息由编者从已发表的学术论文中独立整理。
- **社区贡献**：部分量表由用户通过「提交新量表」功能贡献。

感谢 OBHRM百科及其维护者为 OB/HRM 学术社区提供的宝贵资源。

量表信息来源于已发表的学术文献及 [OBHRM百科](https://www.obhrm.net/)，经过整理和标准化处理。每条量表都标注了原始来源。

可以。页面底部的「下载」按钮会保存完整的单文件 HTML（约 10MB），包含所有数据，双击即可在浏览器中打开使用。
